
# СВК-1 — Средство выработки личного и открытого ключей

Программное средство криптографической защиты информации (СКЗИ), предназначенное для генерации, безопасного хранения и уничтожения ключевой информации. Разработано в соответствии с требованиями СТБ 34.101.27 (уровень 1).

## Основные возможности
- Авторизация: разграничение прав доступа, защита от брутфорса (блокировка после 3 попыток).
- Генерация ключей: создание ключевых пар (512–4096 бит) на основе криптографически стойкого ГСЧ.
- Хранилище: управление сгенерированными ключами (просмотр, удаление).
- Защита целостности: проверка цифровой подписи манифеста (ECDSA P-256) и контроль SHA-256 хэшей.
- Проверка SBOM: анализ состава программного обеспечения.
- Атомарное обновление: безопасная замена файлов с откатом при сбое.
- Аудит: логирование событий безопасности с возможностью очистки.
- Идентификация: сбор уникального отпечатка системы (Hardware ID).

## Технологии
- Язык: Python 3.11+
- Интерфейс: PySide6 (Qt6)
- Криптография: cryptography (ECDSA), hashlib (SHA-256)
- Сборка: PyInstaller (сборка в единый .exe)

## Установка и запуск

1. Клонируйте репозиторий:
git clone https://github.com/pixiell1/svk-1-crypto-system.git
cd svk-1-crypto-system

2. Установите зависимости:
pip install PySide6 cryptography

3. Запустите программу:
python main.py
